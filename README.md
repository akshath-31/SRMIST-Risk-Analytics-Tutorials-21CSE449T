## About the Course

Risk Analytics focuses on identifying, assessing and managing risks using analytical methods and data-driven decision-making.

The course covers risk management fundamentals and their applications across five major areas:

1. Risk Introduction and Impacts
2. Banking Sector
3. Insurance Sector
4. Healthcare Sector
5. Human Resource Analytics

Students explore topics such as credit risk, capital adequacy, insurance fraud detection, healthcare outcomes, customer analytics, employee retention and talent management.

### How to Open and Run a Notebook

**Option A – Google Colab (Recommended)**

1. Open the required `.ipynb` file from this repository.
2. Download the notebook using the GitHub download option.
3. Visit [Google Colab](https://colab.research.google.com/).
4. Select **File → Upload notebook**.
5. Upload the downloaded notebook.
6. Run the cells sequentially using the play button or **Runtime → Run all**.

**Option B – Run Locally Using Jupyter Notebook**

1. Clone the repository:

   ```bash
   git clone https://github.com/akshath-31/SRMIST-Risk-Analytics-Tutorials.git
   ```

2. Navigate to the project directory:

   ```bash
   cd SRMIST-Risk-Analytics-Tutorials
   ```

3. Install Jupyter and commonly used Python libraries:

   ```bash
   pip install jupyter pandas numpy matplotlib seaborn
   ```

4. Launch Jupyter:

   ```bash
   jupyter notebook
   ```

5. Open the required notebook and execute its cells.

**Note:** Some notebooks may require additional Python packages or external datasets. Check the individual notebook for its requirements and instructions.
